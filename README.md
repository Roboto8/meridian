# The Meridian

A Guardian-style news site — fast, mobile-first, with an endless scroll feed.

**Live:** https://roboto8.github.io/meridian/

Built with Vite + React + React Router. The newsroom — 32 original articles across
8 sections, each with a matching documentary photo — was generated by a fan-out of
writer agents, then rendered into a Guardian-inspired design (slab-serif headlines,
section accent colours, infinite "doom-scroll" feed).

## Develop
```bash
npm install
npm run dev
```

## Build
```bash
npm run build      # -> dist/
```
